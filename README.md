# Site Analyze — Belarus to Poland

Rust-first исследовательская платформа для воспроизводимого анализа нестабильного
веб-сайта и применяемых к нему инструментов.

## Текущее состояние

Новая платформа ещё не реализована. Существующий Python-прототип полностью и без
изменения содержимого перемещён в:

[`legacy/python-v1/`](legacy/python-v1/)

Архитектура, этапы реализации, критерии качества и Definition of Done описаны в:

[`IMPLEMENTATION_PLAN.md`](IMPLEMENTATION_PLAN.md)

## Структура

```text
.
├── README.md
├── IMPLEMENTATION_PLAN.md
└── legacy/
    ├── README.md
    └── python-v1/
        ├── knowledge/
        ├── screenshots/
        ├── *.py
        ├── *.png
        ├── *.html
        └── __pycache__/
```

`legacy/python-v1` является неизменяемым источником требований и исторических
наблюдений. Новый код не должен импортировать legacy-модули напрямую. Нужное
поведение переносится в новую систему через тесты, типизированные контракты и ADR.

## Правила до начала реализации

1. Не изменять файлы внутри `legacy/python-v1` без отдельного решения и фиксации
   причины.
2. Не считать исторический Markdown структурированным источником истины.
3. Не размещать новый Rust- или Python-код внутри `legacy`.
4. Новый Rust workspace создаётся в корне проекта согласно master plan.
5. Любой импорт legacy-данных должен сохранять ссылку на исходный путь и SHA-256.
